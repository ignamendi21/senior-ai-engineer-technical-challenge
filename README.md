# Senior AI Engineer Technical Challenge

This repository contains a Senior AI Engineer technical challenge organized into three parts:

1. **Magic: The Gathering AI Assistant**
2. **Code review exercise**
3. **Senior solution architecture exercise for a healthcare client**

## Current status

Phases 1–3 of Part 1 are implemented:

- Structure-aware Comprehensive Rules ingestion
- Hybrid multilingual rules retrieval
- Deterministic Magic card API access
- Explicit LangGraph orchestration with grounded answering and demo conversation memory

[`magic-assistant/`](magic-assistant/) contains the implementation. [`code-review/`](code-review/) and [`solution-design/`](solution-design/) remain placeholders.

Part 1 currently provides a development-only OpenAI/LangGraph terminal assistant. No web API, final UI, production deployment, or implementation for Parts 2 and 3 is included. Engineering decisions are recorded in [`decisions.md`](decisions.md).
