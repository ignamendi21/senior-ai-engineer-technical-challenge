# Part 3 — Healthcare Clinic Solution Design

This directory contains the proposed architecture for a local clinical decision-support assistant for the private-clinic scenario.

Read the proposal: [`../solution_design.md`](../solution_design.md).

The scope covers local data residency, protocol retrieval, deterministic clinical calculations, source validation, operational simplicity, non-goals and key project risks. It is a proposed architecture and clinical decision-support design—not a deployed system, autonomous clinician, or certified medical device.
